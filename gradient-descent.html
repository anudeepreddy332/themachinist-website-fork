Gradient Descent

Training a machine learning model means finding the set of parameters that minimize a loss function.

5 min read Intermediate

What is gradient descent and why does it matter?

Training a machine learning model means finding the set of parameters that minimize a loss function. For most models of interest, there is no closed-form solution — you cannot solve for the optimal weights directly. Gradient descent solves this by iteratively moving parameters in the direction that reduces loss the most. It is the foundational optimization algorithm behind linear regression, logistic regression, and neural networks. Without it, training models on large datasets would be computationally infeasible. The core idea is simple: compute the gradient (the slope of the loss function at the current parameter values), then take a small step in the opposite direction. Repeat until the gradient is near zero. This turns a global optimization problem into a local search that works well in practice, especially for convex loss surfaces. The challenge is choosing the step size (learning rate) and handling non-convex surfaces with many local minima or saddle points.

How it works

Gradient Descent

Gradient descent is a first-order iterative optimization algorithm. Given a parameter vector θ and a differentiable loss function J(θ), the update rule at step t is:

θ_{t+1} = θ_t - η · ∇J(θ_t)

where η > 0 is the learning rate (step size) and ∇J(θ_t) is the gradient vector of partial derivatives evaluated at θ_t. For a dataset of m examples, the full-batch gradient is:

∇J(θ) = (1/m) Σ_{i=1}^m ∇L(f(x_i; θ), y_i)

In practice, computing the gradient over the entire dataset is expensive. Mini-batch gradient descent approximates the gradient using a random subset of size B (typically 32–256). This introduces noise but allows faster updates and better generalization. The standard SGD update is θ = θ - η·∇J(θ).

A critical hyperparameter is the learning rate. If η is too large, the algorithm may overshoot the minimum and diverge. If too small, convergence is slow. A common failure mode is getting stuck in a local minimum or, more often in high dimensions, a saddle point where the gradient is zero but the point is not a minimum. Vanishing or exploding gradients can also disrupt updates, especially in deep networks.

Several variants address these issues. Momentum SGD adds a velocity term: v = γv + η·∇J(θ), θ = θ - v, where γ=0.9 is typical. This dampens oscillations and accelerates convergence. Nesterov Accelerated Gradient (NAG) looks ahead along the momentum direction before computing the gradient. Adaptive methods like Adam use per-parameter learning rates with default hyperparameters β₁=0.9, β₂=0.999, ε=1e-8 in PyTorch. Gradient clipping by norm is applied when ||g|| > threshold, rescaling g = g·(threshold/||g||) to prevent exploding gradients.

For convex loss functions like logistic regression, gradient descent with constant step size converges at O(1/k) rate. In practice, learning rate schedules help: warmup linearly increases η from 0 to target over the first 5–10% of steps, and cosine annealing decays it as η_t = η_min + 0.5(η_max - η_min)(1 + cos(πt/T)).

Important: Choosing an appropriate learning rate is critical. Too large a value can cause divergence, while too small a value leads to slow convergence. Adaptive methods like Adam can help mitigate this issue.

In practice

PYTHON
import numpy as np

# Minimize f(x) = (x-3)^2
def f(x):
    return (x - 3)**2

def gradf(x):
    return 2 * (x - 3)

x = 0.0          # initial guess
lr = 0.1
for t in range(100):
    x = x - lr * gradf(x)
print(x)  # ~3.0
PYTHON
# Mini-batch gradient descent for linear regression
import numpy as np

# Generate synthetic data
np.random.seed(42)
X = np.random.randn(100, 1)
y = 2 * X + 1 + 0.1 * np.random.randn(100, 1)

# Add bias term
X_b = np.c_[np.ones((100, 1)), X]

# Initialize parameters
theta = np.random.randn(2, 1)
lr = 0.01
n_epochs = 1000
batch_size = 32
m = len(X_b)

for epoch in range(n_epochs):
    # Shuffle data
    indices = np.random.permutation(m)
    X_b_shuffled = X_b[indices]
    y_shuffled = y[indices]
    for i in range(0, m, batch_size):
        X_batch = X_b_shuffled[i:i+batch_size]
        y_batch = y_shuffled[i:i+batch_size]
        gradients = 2/batch_size * X_batch.T @ (X_batch @ theta - y_batch)
        theta = theta - lr * gradients

print(theta)  # ~[[1], [2]]

Key takeaways

What you now know
  • Gradient descent updates parameters by moving in the opposite direction of the loss function's gradient, using the rule θ = θ - η·∇J(θ).
  • The learning rate η is the most critical hyperparameter — too large causes divergence, too small slows convergence.
  • Mini-batch gradient descent with batch sizes 32–256 is the standard for training neural networks, balancing speed and noise.
  • Momentum (γ=0.9) and adaptive methods like Adam (β₁=0.9, β₂=0.999) improve convergence on non-convex surfaces.
  • Gradient clipping by norm prevents exploding gradients in deep networks, rescaling when ||g|| exceeds a threshold.
